FM1 Virooos TEST59 - amplitude modulation matrix

Adds original matrix targets 1 (patch volume), 2 (channel-volume multiplier),
and 80 (amplitude-velocity depth). Forty-two targets are connected.
Patch volume retains original fractional table interpolation and 0..127 clamp.
Channel-volume modulation uses the original 0..2 multiplier, combined with the
existing MIDI CC7/CC11 gains. Velocity depth retains the original fractional,
bipolar amplitude curve; the native INIT linear-velocity setting 128 is retained
when no velocity-depth modulation is applied. Voice-local cached velocity gain
avoids repeated exponent calculations when its input is unchanged.
Existing 32-sample gain smoothing is preserved. Removing the matrix restores
base gain, and MIDI mute remains effective. Phase and envelope are not reset.

50 retained presets configure non-neutral routes to these new destinations.
533 presets configure a route to at least one supported destination.
Try C4 BlkvelvtSV or C23 Digedi JS for LFO-driven patch-volume movement.
C15 CreameryBC or C66 MoveMyMWBC uses the mod wheel; C0 AutoBendBC and C34 Freno BC
use note key tracking. Numbers are original zero-based programs on the display.
Check four-note CPU average/peak, xruns and deadlines. This build has not been
physically tested on an FM-1.
