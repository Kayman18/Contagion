FM1 Virooos TEST68 - Noise Color modulation

Connects original matrix destination 91, bringing the total to 64 connected
sound destinations. Uses the original rounded 0..127 color, filter frequency
and gain curves, including the white-noise bypass at 64. The existing cached
noise setup only recalculates coefficients when the rounded color changes.
No added persistent state; PRNG and low-pass history are preserved. Removing
the matrix restores the base color. Per-voice velocity sources remain separate.

Hardware examples (original zero-based programs):
C73 NoiztoyzJS - LFO3 drives Noise Color.
F52 Haunted JS and F68 MonolithJS - LFO3 drives Noise Color.
G120 Whales JS - LFO1 drives Noise Color.
Hold notes long enough to hear the changing noise spectrum. Report CPU average,
peak, xruns/deadlines and any clicks; repeat with four-layer unison if desired.
