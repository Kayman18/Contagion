BAND19 EXP — live waveform transitions
====================================
Install release/FM1-Virooos-BAND19-Experimental.fwsc.
Identity FM-1_15007419. Source and tests included.

Changes
- Manual OSC1/OSC2 waveform selections and OSC3 mode changes now update held
  voices through the live cache instead of triggering panic/mute/reload.
- 32 exact 2049-float cache slots, up from 16. Wave bank format unchanged.
- Preload each selected wave's bands 0–4 plus band 13. Keep these three
  fundamental fallback tables protected from eviction until next preset load.
- A cold voice builds its exact band-13 table first (2048 harmonic operations),
  then its requested band. Cold/stolen voices preempt long reconstruction jobs.
- Safe fallback uses equal or fewer harmonics than the requested pitch band.
  A stolen voice cannot start using an unrelated old voice's wave.
- Rapid scans may use a completed older request belonging to that client while
  the latest request loads. Stop scanning and every client converges to its
  exact requested wave and band. No all-scan cancellation starvation.
- Table replacement captures the old sample at the current oscillator phase.
  A linear correction removes the instantaneous step and ends after 128
  samples (2.90 ms at 44100 Hz). This is dezippering, not two-table crossfade.
  Phase/envelope remain intact. Exact settled DSP is preserved.
- Old cache slots stay pinned until correction capture is finished; audio
  never waits for reconstruction. No double-precision math added to audio.

Validation
- 4096 rapid replacements: maximum instantaneous correction error 1.1921e-7.
- 98304 scan requests across 12 clients and 64 waves: 98181 exact published
  table checks; no missing table after all clients first became ready.
- New/cold/stolen clients interrupt long builds; delayed acknowledgement
  protects old samples; all references released on shutdown.
- 256 manual MIDI wave changes while four notes held: no mute and no note loss.
  Rendered 580096 stereo frames; zero silent 256-frame blocks.
- 896 bands / 1835904 samples reconstructed and published byte-exactly.
- Four-voice settled rendered audio remains byte-identical to full-table data.
- ASan/UBSan cache, concurrent publication, preload, transitions, voice tests.
- Native firmware builds; FWSC CRCs, exact application and loader checked.
- User patch storage regression passes; record schema unchanged.

Limits / hardware test
Software regression work for this checkpoint is complete. Physical hardware
CPU, deadlines/xruns and listening tests have NOT been performed here.
The cache cannot reproduce every step of an arbitrarily fast 64-wave scan
instantaneously. It coalesces requests, retains safe playable tables, and
converges when movement stops. A cold uncached wave still needs background
service; the temporary fundamental band can sound thinner and can be silent
for source waves with no fundamental. This is not a zero-latency guarantee.
Preset loads, storage writes and LFO table loads still use their explicit
mute transactions; this change addresses live oscillator waveform selection.
