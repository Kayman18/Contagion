FM1 Virooos TEST62 - unison-detune matrix

Adds original matrix destination 59 (unison detune). Forty-three destinations
are now connected. Fractional modulation uses the original detune curve and
0..127 clamp. Each layer retains its side and odd-stack pitch offset.
Oscillator pitch, filter key tracking and pitch-following saturation update
without retriggering envelopes or resetting oscillator phase/BLEP state.
Removing the route restores base detune. Unison OFF and an odd-stack center
remain unaffected. Pitch setup code is shared to avoid duplicating the DSP.

Analog Boost from TEST61 remains included. Its hardware CPU/underrun results
have not yet been supplied. TEST60's reported baseline was 47% average,
56% peak, zero xruns/deadlines and clean four-layer unison.

Try C21 Devlish SV, original zero-based program 21 in bank C: hold a note and
move the mod wheel. Its original nine-layer stack is capped to four, as before.
G109 Taurus JS also routes mod wheel to detune and is capped to four.
Some presets name this destination but have a neutral route, use no unison,
or use the original Random source that is overwritten by the controller array;
the port retains that source behavior rather than inventing movement.

Validation:
4608 layer cases against the original matrix/detune curve; maximum cents error
2.2e-6. Sanitized checks verify phase/pending-BLEP preservation, matrix removal,
and inert behavior with unison disabled.
Full and reduced routing each cover 78450 cases and 9649350 compared values.
Existing pitch, filter and unison regressions passed.
All 650 presets render finite, nonzero stereo output over 4096 frames each.
Unison and Analog Boost host control scripts passed.
Firmware packaging, cache layout and executable-RAM checks passed.
