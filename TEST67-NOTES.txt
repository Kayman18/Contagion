FM1 Virooos TEST67 - oscillator 3 modulation

Connects matrix destinations 97 (volume), 98 (semitone) and 99 (detune),
bringing the total to 63 connected destinations. Twenty-five retained presets
configure non-neutral routes to these targets; routes remain inert when the
selected oscillator mode does not use the independent controls.

Independent oscillator 3 modes use modulated volume, rounded semitone tuning
and interpolated original detune curves. Slave mode retains oscillator-2
controls. Off stays off. Removing routes restores base controls without
resetting phase, envelopes or pending BLEP corrections.

Corrects earlier oscillator-3 pitch handling: independent modes also receive
oscillator-2 matrix pitch modulation, matching the captured original Engine.
Discrete rounding setup now runs in flash beside matrix evaluation, recovering
276 bytes of executable RAM versus the first TEST67 implementation.

Hardware example: C54 JoeZolo BC (original zero-based program number).
Hold notes and move the mod wheel to vary oscillator-3 level. Also compare
C101 S&HOrganBC and C119 TwotonesBC. Test four-layer unison for heavier load.

Validation:
23,040 oscillator-3 reference cases across all amounts, boundary/fractional
sources and modes 0..4. Maximum increment error 1.317e-8; gain error 1.535e-7.
Direct original Engine comparison confirms oscillator-2 pitch following.
Phase/BLEP preservation, band selection, voice isolation, matrix removal and
block-size invariance passed. Pitch, envelope, portamento, matrix routing and
unison modulation regressions passed. All 650 presets rendered finite/nonzero
audio under ASan/UBSan, 4096 stereo frames each. Unison and Analog Boost host
control scripts passed. Target layout/cache and firmware CRC/package checks
passed. These checks do not establish real-device CPU performance.
