FM1 Virooos TEST50 — first audible modulation-matrix destinations

New: factory matrix routes now control cutoff and resonance for both filters.
Fractional values, linked cutoff, multiple routes to one destination and
route-amount modulation retain the original evaluation order. 394 of the
650 retained presets have configured routes to these four destinations.

Sources: pitch bend, channel pressure, mapped MIDI controllers, both envelopes,
all three LFOs, note velocity, release velocity and key follow. Release velocity
starts at note-on velocity; explicit MIDI note-off provides its release value.
Pedal-deferred releases use zero, matching the original. The original processor
currently overwrites its Random source with zero at control time; this port
matches that behavior rather than introducing a different random modulation.

Arp remains absent; all 118 arp presets remain excluded. EQ and distortion
remain. Delay, reverb, chorus and phaser remain excluded.

Suggested hardware check:
1. Select bank C, program 0, AutoBendBC (first PRESET turn from INIT).
2. Hold notes and move the mod wheel. Filter response should now change.
3. Try C program 7, ChilloutJS, with four held notes and wheel movement.
4. Note average/peak CPU, xruns and deadlines. No hardware CPU result is claimed.
