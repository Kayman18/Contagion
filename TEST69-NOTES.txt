FM1 Virooos TEST69 - oscillator 2 detune modulation

Connects original matrix destination 15, bringing the total to 65 connected
sound destinations. Thirty-four retained presets configure non-neutral routes
to it; this count includes routes whose source can be inactive.

Uses the original fractional detune curve. Oscillator 2 receives the detune
change; oscillator 3 in slave mode receives the opposite change. Independent
oscillator 3 modes retain their own detune and shared pitch modulation.
Pitch-band updates preserve oscillator phases and pending BLEP corrections.
Removing the matrix restores the base detune without retriggering voices.

Hardware examples (original zero-based program numbers):
C21 Devlish SV, C33 FnkNastyBC, D70 NylSolo HS and G28 EPhase BC:
hold notes and move the mod wheel. Other assigned destinations may also move.
C17 Da Funk BC uses LFO1; D28 DX-Pno1 HS uses LFO2.
Report CPU average/peak, xruns/deadlines and any clicks; repeat with four-layer
unison for a heavier test if desired.

Validation:
8192 reference cases across four base settings, all route amounts, four source
levels and oscillator-3 modes 1..4. Maximum detune error 7.544e-6 cents and
increment error 5.667e-10. ASan/UBSan checks cover phase/BLEP preservation,
band selection, voice isolation, matrix removal and block-size invariance.
Full/reduced/rounded matrix routing, 46080 pitch cases, 23040 oscillator-3 cases
and 4608 unison-detune cases passed. All 650 presets rendered finite/nonzero
audio for 4096 stereo frames each under ASan/UBSan. Unison and Analog Boost
host scripts passed. Target layout/cache and firmware CRC/package checks pass.
