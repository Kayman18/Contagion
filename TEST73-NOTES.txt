FM1 Virooos TEST73 - main oscillator level and saturation modulation

Connects matrix destination 22, bringing the total to 72 connected sound
destinations. Forty-five retained presets configure non-neutral routes to it.
This completes the mixer destinations: balance, sub/noise/ring levels and
main oscillator level.

Below the center, the original fractional volume curve controls the main
oscillators, sub, oscillator 3 and punch. Above the center, oscillator volume
stays at unity and saturation drive rises. Noise and ring levels stay
independent. Saturation now accepts fractional levels: waveshaper-table
interpolation, exponential rate-reducer anchors and low/high-pass curves
match the captured source. Integer coefficient tables retain their existing
path. The noise/reducer/filter histories are not reset by a level change.
Removing the matrix restores base level and saturation drive.

Hardware examples (original zero-based programs), hold notes and move wheel:
D59 Manfman HS, F9 Bassta JS or F79 Outland JS.
C28 Etheral SV also modulates ring level. Other assigned destinations may move.
Report CPU average/peak, xruns/deadlines and any clicks. Four-layer unison is
useful for a heavier test. Above center, the saturation mode determines how
obvious the change is; saturation OFF leaves that upper range at unity.

Validation:
38400 matrix comparisons covering all 15 saturation modes, five base levels,
all amounts and four source levels. Maximum gain error 1.698e-7; coefficient
error 2.643e-7; rate-period relative error 5.734e-7. ASan/UBSan checks preserve
saturation state, restore base on removal, isolate voices and verify block
size invariance. Integer and fractional saturation audio suites passed,
including rate/frequency following and all four filter routings.
Full/reduced/rounded matrix routing, source-level and balance regressions pass.
All 650 presets render finite/nonzero audio over 4096 stereo frames each under
ASan/UBSan. Unison/Analog Boost host scripts, target placement/cache checks and
firmware CRC/package verification passed.
