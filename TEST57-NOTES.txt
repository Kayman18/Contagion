FM1 Virooos TEST57 - pulse-width modulation matrix

Adds original destinations 7 (oscillator 1 pulse width), 12 (oscillator 2 pulse
width), 47 (LFO1 PWM depth), and 74 (velocity-to-PWM depth). Thirty-four matrix
destinations are connected. Fractional depths and original clamps are retained,
including the negative width range and duty wrap at the upper endpoint.
Existing LFO3 width contributions combine with these routes. Oscillator 3 in
slave mode receives oscillator 2's updated duty in the same control block.
Phase and pending BLEP state are preserved. The existing per-voice width cache
also restores base widths when modulation is removed. No persistent RAM added.

59 retained presets configure non-neutral routes to the four new targets.
488 retained presets configure a route to at least one supported destination.
Try C7 ChilloutJS, C11 Comm basSV, or C23 Digedi JS for LFO-driven width motion.
C71 NastyFX JS uses the mod wheel for oscillator 1 width. Numbers are original
zero-based program numbers shown on the preset page. Check CPU average/peak,
xruns and deadlines. TEST57 has not been tested on a physical FM-1.
