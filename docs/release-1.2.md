Contagion 1.2 for the M‑VAVE FM‑1 includes the eight-voice synth, all 1,525 factory presets, and the 34-table flash cache.

- Two two-lane generative sequencers, OXI Style and SIG+ Style. Both have a live Note Weights keyboard. SIG+ adds weighted durations, ratchets, slides, and duration-based Morph.
- 32 named USER patch slots with panel auto-recall and a matching USB MIDI editor.
- Eight USER SEQUENCE slots on **SEL → SCL 3**, with settings for both modes and captured Hold phrases.
- The original 16 USER patch slots retain their flash location and format. USB audio is disabled.

On USER Patches or USER Sequences, use **knob 3** to move the character cursor and **knob 4** to change the character. **Press SAVE to finish.** The [README](https://github.com/Kayman18/Contagion#sequencers) includes screenshots and an operation guide for every sequencer and browser page.
