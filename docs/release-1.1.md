## Contagion 1.1

One eight-voice firmware contains all **1,525 factory presets in 14 Virus A, B, and C banks**. Install the `.fwsc` with the FM‑1 updater. Use the USB‑C editor ZIP for desktop patch editing.

- **SCL page 1** opens the new factory preset list. **SCL page 2** opens USER patches.
- **HOME** holds oscillator, mixer, saturation, voice, pitch bend, and Analog Boost. **FX** holds filters, Distortion, and EQ.
- Factory and INIT volume defaults to **90**. Saved USER volumes are retained.
- **34 full-precision wavetables** install into secondary flash, with coefficient reconstruction available on a cache miss.
- **64-sample de-click fades** cover hard starts, steals, and fast mono retriggers.
- The **offline USB‑C MIDI editor** can browse factories, send supported controls live, edit the full parameter and modulation records, and read or verify USER slots.

The updater package, flash cache fallback, SCL navigation, and editor SysEx round-trip passed in simulation. Physical FM‑1 USB operation and timing of the release build are pending.
