BAND18 EXP — individual user-slot SysEx backup/restore

Effects remain deferred. New native protocol, NOT original Virus SysEx import.
BAND16/17 native bank format and patch names remain compatible.

USB MIDI operation:
1. Send transfer/Request-User-01.syx (or another slot1..16) and capture the
   response as a .syx file in your MIDI software. Only SAVED slots are exported.
2. Inspect a captured file:
   python3 tools/user_patch_sysex.py inspect backup.syx
3. Prepare restore into slot2 (overwrites that saved USER slot):
   python3 tools/user_patch_sysex.py restore 2 backup.syx restore.syx
4. Send restore.syx; capture the acknowledgment and inspect it with the same
   utility. Status0 means written and readback-verified. Recall with K2 later.
The Python utility reads/writes files only; it does not open a MIDI port.
Python3 is required, with no extra packages. Factory presets are not overwritten.
To extract a native record: python3 tools/user_patch_sysex.py extract backup.syx patch.vcp
To create a request: python3 tools/user_patch_sysex.py request 2 request.syx
Repeat per slot to back up a whole bank; no one-command bank transfer yet.

Restore uses the same audio mute acknowledgment and main-loop verified flash
write as SAVE. It does not automatically recall the incoming patch or change
current synth settings, but temporarily mutes/panics held notes for storage.
Busy transfers are rejected for retry; there is no hidden pending transfer queue.

Protocol v1: F0 7D 56 49 52 01 command slot payload checksum F7.
Slot is0..15 on the wire. Commands1=request,2=dump,3=restore,4=status.
Payload is7-bit packing: one high-bit mask followed by up to7 low-bit bytes.
Requests contain no payload; dump/restore contain189 raw record bytes; status
contains one raw byte. Sum from7D through checksum modulo128 is zero.
Full dump/restore frame226 bytes, below platform's640-byte receive buffer.
Status0=saved,1=busy/retry,2=empty,3=invalid/incompatible,4=write failed.
Schema/length/CRC and ranges are checked before a restore is queued.
Received response commands never cause a write.

Validation:host export; independent Python decoder; exact restore/dump roundtrip;
current sound unchanged until recall; restored values/matrix after simulated
reboot; busy/empty/error replies; invalid record no-write; injected failed-write
reply with no slot created. Wire ASan/UBSan test rejects1792 single-bit corruptions
and all truncations. Target build and firmware package checks pass.
Physical USB transfer and real flash persistence remain untested.

Normal RAM67684 /98304 and pool155720 /344064 unchanged from BAND17.
Image537296 /581564 bytes. Transfer uses bounded temporary main-loop buffers.
Audio DSP and default loading budget unchanged. BAND17 rollback included.
