FM1 Virooos - target publication adapter prototype 4

Source-only checkpoint. Firmware remains TEST74. No experimental cache code
is linked into the running firmware yet.

Implemented experimental/band_publication.h:
Host builds retain C11 acquire/release atomics for threaded tests.
Explicit VC_BAND_FM1_SINGLE_CORE builds use aligned 32-bit volatile mailbox
words with csync and compiler memory barriers around reads/writes, following
the BSP's publication pattern. No read-modify-write or interrupt masking.
Static assertions enforce 32-bit word width and four-byte alignment.
PLAT_HOST rejects the target adapter, preventing accidental substitution of
volatile words for host-thread atomics.

Scope restriction:
The target adapter is intended only for CPU0 main-loop/background work and
the CPU0 audio ISR. It is not certified for a CPU1 worker or arbitrary SMP.
Initialize/reset only while both owners are stopped. The audio callback must
finish reading old tables before its block-boundary acknowledgement.
The host tests validate the protocol using C11 atomics, not the physical FM1
memory system. Generated-code checks do not replace a hardware stress test.

Target verification:
Run JIELI_TOOLCHAIN=... bash tests/check-band-target.sh.
pi32v2/r3 object compilation passed. Symbol audit confirms no __sync_* or
__atomic_* helper dependencies. Disassembly confirms no calls in audio request,
audio release or boundary publication; each contains csync. These functions
contain fixed-size work and no reconstruction or wait loop. The cache service
and handoff are not firmware-linked yet, so placement/branch reach remain open.
Reproducible evidence: validation/band-target-publication-prototype4.json,
band-handoff-fm1-symbols.txt, band-handoff-fm1-disassembly.txt and
band-target-layout.txt.

Measured target structures:
Builder 48 bytes.
Cache metadata + coefficient scratch + builder 2536 bytes.
Whole handoff including cache 2844 bytes.
Sixteen tables 131136 bytes; peak metadata 256 read-only bytes.
Total planned table/metadata/peak accounting 134236 bytes, plus shared sine
constants and code. This is not the final linked firmware RAM footprint.

Regression:
ASan/UBSan concurrent run passed 141670 exact table comparisons, 233 concurrent
boundary swaps and 30000 background calls in this run. A separate ThreadSanitizer
run passed with no reported races (2704 comparisons, 28 swaps). Counts vary
with scheduling. Delayed acknowledgement, stable request convergence and
release/pin cleanup all passed.
Files: validation/band-handoff-prototype4-asan.txt and
validation/band-handoff-prototype4-tsan.txt.
