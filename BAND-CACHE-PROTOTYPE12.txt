BAND12 EXP — on-device cache diagnostics and adjustable worker budget

Effects remain deferred. No new hardware measurement claimed.

Press GLO to see CPU, then GLO again for WAVE CACHE. This replaces the
experimental build's disabled benchmark page. Local touch notes now work
on this page; entering/leaving it does not send benchmark/panic events.

READY /16: complete resident tables, including unreferenced cached entries.
WAIT /12: last background snapshot of clients not yet committed to their
requested exact wave/band. This is a count, not a time or cumulative misses.
BUILT: completed reconstructions since the latest preload reset.
CANCELLED: abandoned jobs since that reset.
FAILURES: decoder/builder failures since that reset; should remain zero.
BUILD %: sample progress of the current job; 100 when no job is active.
BUDGET: harmonic steps per active-playback background service call.
WORK MAX MS: largest observed elapsed time of such a service call, measured
with millisecond resolution. Includes audio interrupt preemption; it is not
pure background CPU time and zero may mean less than one clock tick.
Muted preload/startup work is excluded from WORK MAX MS.

K1 adjusts BUDGET in256-step increments from256 to8192; default1024.
It is a volatile diagnostic setting, not stored with presets or settings.
K2 resets WORK MAX MS and the existing CPU/performance counters, not cache
contents or BUILT/CANCELLED/FAILURES. Those reset with preload preparation.
The default worker budget and DSP remain unchanged. Increasing budget can
lengthen main-loop work and affect responsiveness; measure rather than assume.

Test: use a wave-modulated preset; note WAIT, BUILT, FAILURES and WORK MAX MS.
Compare budget1024 then2048 while holding the same notes. Return to CPU with
GLO and report average/peak, xruns/deadlines and whether scanning improves.
Changing budget does not itself mute or restart held notes.

Validation: target firmware link; normal TEST74 build remains byte-identical;
backend snapshot tests for distinct/shared preload tables and acknowledged
publication; package CRC/decryption/loader/entry checks. UI layout uses the
existing eight-cell screen; not visually or physically tested on hardware.

Memory: normal61044 /98304, pool155720 /344064 bytes (unchanged from BAND11).
Image532340 /581564 bytes. BAND8 and TEST74 rollback firmware included.
