FM1 Virooos TEST60 - fixed-pool unison

New UNISON page after FACTORY PRESETS, reached with ALGO or FX.
First row: voice count (OFF/2/3/4), detune, stereo width, LFO phase spread.
Second row: key mode and portamento. Changing voice count stops current notes.

Uses the existing four physical DSP voices:
OFF: four-note polyphony.
2 voices per note: two-note polyphony.
3 or 4 voices per note: one-note polyphony.
Old stacks are stolen as complete groups. Mono modes retarget the whole stack;
sustain and hold apply to all layers.

Ported original detune curve, symmetric layer placement, odd-stack pitch offset,
stereo pan law and per-layer LFO trigger offsets. Shared LFOs remain shared.
Factory unison and stereo-width settings are now connected. Of 208 retained
unison presets, 197 request 2-4 voices; 11 request more and are capped at four
and marked partial. No additional normalization was added: stacks can be
louder, and the existing output limiter can engage.

Still limited: maximum four layers (original supports sixteen), native hard
voice stealing, no unison-detune matrix target 59 yet. Existing target 60
modulates stereo width. Other unfinished synthesis/matrix features remain;
PARTIAL does not mean only unison is missing. No arp or excluded effects added.

Validation:
Original reference detune curve: all 128 values.
Original reference stereo-width law: all 128 values.
Native sanitized tests cover 1-4 layers, all detune and width values, explicit
LFO phase spread, audible finite output, sustain, group stealing, mono modes,
hold, block-size invariance and mode changes.
All 650 presets: 80600 parameter checks and 4096 stereo frames each, finite
and nonzero output. UI host test verifies page 25 and 2/4 voice behavior.
Target layout and firmware packaging checks passed.
