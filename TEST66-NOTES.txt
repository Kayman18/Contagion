FM1 Virooos TEST66 - portamento modulation

Connects original matrix destination 5 (portamento), bringing the total to
60 connected destinations. Eighteen retained presets configure non-neutral
routes to it.

Each voice now caches its own effective glide amount and coefficient.
The original exponential time mapping, fractional values, clamping and zero
bypass are retained. A control step glides using the previous effective amount,
then evaluates the new matrix amount, matching the captured source order.
Small coefficients use a stable calculation to avoid float cancellation.

Mono legato preserves the current modulated glide across retargeted notes,
including when the patch's base portamento is zero. This also applies to all
members of a unison stack. Pitch-bend updates preserve the effective glide.
Removing/rebinding the matrix restores the base amount; it does not retrigger
the envelope or reset oscillator phase.

Hardware examples (original zero-based program numbers):
C72 NewVoV4 BC: play overlapping/legato notes while moving the mod wheel.
Both note velocity and mod wheel affect its glide amount.
C3 BC NewVoV3: compare velocities during legato playing.
Glide is heard during note transitions, not by holding one settled pitch.

Validation:
5120 reference cases across all route amounts, boundary/fractional sources,
four base values and 44100/48000 Hz. Maximum amount error 5.601e-6, coefficient
error 8.156e-8 and trajectory error 2.620e-5 semitones.
ASan/UBSan checks cover four mono modes, 1..4-layer unison, zero transitions,
independent voice velocities, pitch bend, matrix rebind/removal and audio
block-size invariance.
Existing source key-mode comparison passed with matrix support compiled in.
Full/reduced/rounded routing, unison-detune, envelope, LFO timing and unison
regressions passed. All 650 presets render finite/nonzero output over 4096
stereo frames each. Unison/Analog Boost host control scripts passed.
Target cache/layout and firmware package checks passed.
